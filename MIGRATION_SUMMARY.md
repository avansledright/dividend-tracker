2. **docker-registry-credentials** (username/password) - Docker registry auth
3. **alpha-vantage-key** (string) - Optional API key for stock data

Kubernetes secret created automatically:
```bash
kubectl create secret generic dividend-tracker-secrets \
  --from-literal=alpha-vantage-key="<from jenkins>" \
  --from-literal=secret-key="<auto-generated>"
```

## Deployment Flow

1. **Developer pushes code** → Triggers Jenkins webhook
2. **Jenkins builds image** → Tags with build number
3. **Jenkins pushes image** → To 192.168.1.23:5000
4. **Jenkins creates secrets** → If not exists
5. **Jenkins deploys MongoDB** → If not exists, waits for ready
6. **Jenkins deploys app** → Rolling update with health checks
7. **Jenkins verifies health** → Tests `/finance/health` endpoint
8. **Traefik routes traffic** → From `home.home/finance/` to pods
